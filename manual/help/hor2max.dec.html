Function index · hor2max.dec() method

skyscapeR 2.0.9004

Find the northern declination limit of a horizon

Description

Estimate the largest declination indicated by the horizon near true north.

Usage

hor2max.dec(hor, alt = 0, range = 25)

Arguments

hor

Either a skyscapeR.horizon object or the latitude of the place.

alt

Altitude of the horizon at northernmost point. Only necessary if no skyscapeR.horizon object is provided. Default is 0.

range

Range of azimuths to check for minimum declination. Default is 25 degrees either side of North.

Details

Terrain relief can shift the limiting sightline away from the meridian. The function samples bearings at 0.01-degree spacing within the specified half-width around 0 degrees. It calls az2dec at each bearing with the stored horizon, or with the supplied latitude and constant altitude, then returns the maximum sampled declination. A limited search sector may miss a more extreme sightline elsewhere.

Value

One numeric value in degrees, the largest declination sampled across the specified azimuth range around north.

Examples

hor <- malta_horizons[[1]]
hor2max.dec(hor)
