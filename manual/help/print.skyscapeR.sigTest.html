Function index · print.skyscapeR.sigTest() method

Print global and local significance results

Description

Report how strongly the observed orientation distribution departs from the fitted null model, overall and within local angular intervals.

Usage

## S3 method for class 'skyscapeR.sigTest'
print(x, ...)

Arguments

x

Object of skyscapeR.sigTest format.

...

Additional arguments to be passed to print.

Details

Start with the stored global Monte Carlo result, then examine the direction, limits and local p-value of each reported interval. The summary gives the tail setting, confidence level and number of simulations. It counts unequal observations at constant null density separately and reports when there are no local regions. The method formats a saved result on the console without recomputing it. Read interval coordinates in the units and coordinate system of the fitted test.

Value

Prints the test summary and global and local results to the console.

Validation

The tested public fits printed the stored global probability and local interval endpoints. A wrapped interval has start greater than end. A plot spanning the full turn displays its two visible segments with the same adjusted probability. See S03 validation in the technical manual.

W01 checked the reported wrapped interval endpoints and adjusted probabilities against a known fit. See the W01 check in the technical manual.

See Also

randomTest, modelTest, plot.skyscapeR.sigTest

Examples

az <- az.pdf(az = c(85, 95, 112), unc = 3, verbose = FALSE)
set.seed(42)
fit <- randomTest(az, nsims = 10, ncores = 1, .res = 2, verbose = FALSE)
print(fit)
