Function index · reduct.theodolite() method

Reduce theodolite readings using a solar sight

Description

Orient a theodolite survey to true north using a timed solar sight, then recover the true bearing of a structural axis.

Usage

reduct.theodolite(
  loc,
  az,
  date,
  time,
  tz,
  az.sun = 0,
  limb,
  alt,
  name,
  ID,
  HWT.ID
)

Arguments

loc

Location, either a skyscapeR.horizon or a vector containing the latitude, longitude and elevation of location, in this order.

az

Array of azimuths. Use ten to convert to decimal degrees if necessary.

date

Date of measurements as a string in the format: 'YYYY/MM/DD'

time

Time of sun-sight measurement in the format: 'HH:MM:SS'

tz

Timezone of input either as a known acronym (e.g. "GMT", "CET") or a string with continent followed by country capital (e.g. "Europe/London").

az.sun

Measured azimuth of the sun. Defaults to zero.

limb

Measured limb of the sun. Options are left, right. If missing the center of the sun will be used for calculations.

alt

Altitude, necessary for automatic declination calculation. If missing and loc is a skyscapeR.horizon object then the altitude will be automatically read from the horizon profile.

name

Names or labels to identify each measurement.

ID

IDs or codes to identify each measurement.

HWT.ID

HeyWhatsThat IDs relating to a previously generated horizon profile for measurement.

Details

The observed difference between the instrument readings to the structure and to the Sun is added to the calculated solar azimuth at the observation time. The routine handles a circle-boundary difference, accounts for the selected solar limb through sunAz and rounds the reference bearing according to the input readings. True bearings lie in [0, 360) degrees. A three-coordinate vector supplies one shared site; for multiple sites, supply a matrix with one latitude, longitude and elevation row per reading. An explicit altitude or a supplied horizon allows the corrected bearing to be converted to declination. Correct time, civil timezone, limb and site are all essential to the reduction.

Astronomical positions require Swiss Ephemeris files covering the epoch. We recommend installing swephRdata; see skyscapeR-package for setup.

Value

A data frame with one row per observation. True.Azimuth is the corrected azimuth in degrees. The table also records the observed azimuth, solar azimuth, time and site coordinates. Where available it includes Altitude and Declination in degrees and the supplied identifiers.

Validation

W02 recovered both independent circle-difference control bearings and retained each site row in a multi-site solar reduction. See the W02 check in the technical manual.

References

Ruggles, C.L.N. (1999). Astronomy in Prehistoric Britain and Ireland. Yale University Press.

See Also

sunAz, ten

Examples

if (requireNamespace("swephRdata", quietly = TRUE)) {
  lat <- ten(35,50,37.8)
  lon <- ten(14,34,6.4)
  elev <- 100
  az <- c( ten(298,24,10), ten(302,20,40))
  az.sun <- ten(327,29,50)
  date <- "2016/02/20"
  time <- "11:07:17"
  
  data <- reduct.theodolite(c(lat,lon,elev), az, date , time, tz= "Europe/Malta", az.sun)
  
  # Declination will be automatically calculated if the altitude is also given:
  data <- reduct.theodolite(c(lat,lon,elev), az, date, time,
  tz="Europe/Malta", az.sun=az.sun, alt=c(2,5))
  
  # Alternatively, the altitude can be automatically retrieved from a horizon profile:
  hor <- malta_horizons[[1]]
  data <- reduct.theodolite(hor, az, date, time, tz= "Europe/Malta", az.sun)
}
