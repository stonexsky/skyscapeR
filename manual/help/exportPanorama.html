Function index · exportPanorama() method

skyscapeR 2.0.9004

Export a horizon as an equirectangular PNG

Description

Write a full-sphere 2:1 RGBA texture for planetaria or image editors.

Usage

exportPanorama(
  hor,
  file,
  width = 4096,
  use.image = TRUE,
  col.ground = "darkgreen"
)

Arguments

hor

A skyscapeR.horizon object.

file

Destination PNG filename. Choose a new filename for each export.

width

Even output width in pixels. Height is half the width. Default 4096.

use.image

Use the attached terrain or photographic texture when available. Set FALSE to export the numerical skyline as a silhouette.

col.ground

Fill colour for a numerical silhouette.

Details

The left edge is true north. Azimuth increases clockwise through east, south and west. The top is the zenith, the middle is zero altitude and the bottom is the nadir. Image exports preserve the calibrated angular bounds and sample source pixels by nearest neighbour. Sky and areas outside photographic coverage are transparent. For a numerical skyline, the ground extends to the nadir over the measured azimuth sector. A missing or modified image triggers a warning and the numerical silhouette is exported instead.

Value

The absolute PNG path, invisibly.

See Also

exportStellarium, importPanorama

Examples

## Not run: 
exportPanorama(hor, "site.png")
exportPanorama(hor, "site-silhouette.png", width = 2048, use.image = FALSE)

## End(Not run)
