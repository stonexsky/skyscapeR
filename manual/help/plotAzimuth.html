Function index · plotAzimuth() method

Plot orientation measurements on a compass grid

Description

Inspect the directions of structural axes on a compass and compare them with candidate rise or set bearings.

Usage

plotAzimuth(
  az,
  obj,
  show.obj.labels = TRUE,
  col = NULL,
  lty = 1,
  lwd = 1.5,
  marks = c("spokes", "rim"),
  obj.position = c("inside", "outside"),
  show.legend = TRUE,
  style = "publication-colour"
)

Arguments

az

Azimuths in degrees clockwise from north. Can be omitted if obj is given.

obj

A skyscapeR.object from skyObject, or a list of these objects. Each group retains its own epochs and styles for displaying the azimuths of celestial objects. Note that this assumes a single location per group and a flat horizon of zero degrees. For a year range, the target colour fills the interval of rising or setting bearings between the stored declination limits. A zero-width interval is drawn as a line.

show.obj.labels

Logical to control whether to display celestial objects names. Defaults to TRUE.

col

Single color or color palette to use for plotting measurements.

lty

Line type to plot measurements. Defaults to 1.

lwd

Line width for measured bearings. Defaults to 1.5.

marks

Draw measured orientations as equal-length "spokes" (default) or short "rim" ticks.

obj.position

Draw target reference lines "inside" the circle or just "outside" its rim. In both positions labels lie outside the circle. The first line names the target and the second gives rise or set. Range endpoints share a label. Non-crossing targets have no reference bearing.

show.legend

With TRUE, show the count and enabled target labels. FALSE centres the bare compass, including its cardinal scale, measured bearings and target lines.

style

Analytical display style, either "publication-colour" (default) or "publication-mono". Monochrome uses grayscale and preserves line styles.

Details

Measurements are drawn as spokes or rim ticks. North is at the top and bearings increase clockwise; repeated bearings can overplot. A data frame supplies the True.Azimuth column. For optional targets the function converts zero apparent altitude to geometric altitude using the session atmosphere. It solves for rising and setting bearings on a level horizon and shows the part of each declination interval that reaches it.

Value

Draws measured bearings and optional target directions on the active graphics device. North is at the top and azimuth increases clockwise.

Validation

W01 checked compass bearings and the inner and outer edges of celestial year-range sectors against their spherical reference bearings. See the W01 check in the technical manual.

See Also

plotBars, orbit, sketchSky, planisphere

Examples

# Plot some azimuth data:
az <- c(120, 100, 93, 97, 88, 115, 112, 67)
plotAzimuth(az)

# To visualize this data against the common solar and lunar targets:
tt <- skyObject('solar extremes', epoch=-2000, loc=c(35,-8), col='red')
plotAzimuth(az, obj=tt)

# To display only celestial objects
plotAzimuth(obj=tt)
