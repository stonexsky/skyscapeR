Function index · plot.skyscapeR.sigTest() method

skyscapeR 2.0.9006

Plot an orientation significance test

Description

Locate the orientations at which the observed summed density departs from the simulated comparison envelope. New tests use an envelope pooled from the observation and simulations.

Usage

## S3 method for class 'skyscapeR.sigTest'
plot(
  x,
  xrange,
  title = NULL,
  col = NULL,
  show.pval = TRUE,
  show.local = FALSE,
  pal = NULL,
  ...,
  obj = NULL,
  xlim,
  show.legend = TRUE,
  style = "publication-colour"
)

Arguments

x

A skyscapeR.sigTest object created with randomTest

xrange

Range of x-axis to plot.

title

Title to add to the plot.

col

Observed density colour. NULL uses the current style.

show.pval

Logical to control whether to print the global p-value. Default is TRUE.

show.local

Draw a separate panel on the same angular scale, with Excess and Deficit rows. Default FALSE. Symbols are ***, **, *, + and an open circle, with upper cutoffs 0.001, 0.01, 0.05 and 0.10. The open circle is centred at the same height as the stars and marks values above 0.10.

pal

Deficit and excess colours in that order. NULL uses the current style.

...

Additional arguments to be passed to plot.

obj

A skyObject or list of target groups for a density or significance plot. Declination plots show single epochs as lines and epoch ranges as bands. Azimuth plots use each group's site latitude to mark rising and setting boundary bearings at a geometric level horizon.

xlim

Earlier name for xrange.

show.legend

Display the density/envelope key and any local significance symbol key. show.pval independently controls the numeric global p-value.

style

Analytical display style, either "publication-colour" (default) or "publication-mono". Monochrome uses grayscale and preserves line styles.

Details

The observed curve and envelope use the azimuth or declination grid stored in the test result. The two-tailed display shades between its lower and upper pointwise bounds; the one-tailed display shades up to the upper bound from zero. Optional annotations show the stored global p-value and the local intervals, coloured by deficit or excess and labelled by p-value symbols. The observed and envelope curves jointly set the visible vertical range. The lower panel identifies adjusted and legacy unadjusted local results. The plot reads the fitted result without repeating the simulations. New local values use maximum-cluster adjustment under the complete null; cluster endpoints remain descriptive, not confidence limits. Legacy fits retain their original unadjusted values. Interpret local regions alongside the whole-curve test.

Value

Draws the empirical density and pointwise comparison envelope. Optional annotations display the global p-value and local regions.

Validation

The tested public fits plotted the stored local interval midpoints and significance symbols. A wrapped interval has start greater than end. A plot spanning the full turn displays its two visible segments with the same adjusted probability. See S03 validation in the technical manual.

See Also

randomTest, modelTest, print.skyscapeR.sigTest

Examples

az <- az.pdf(az = c(85, 95, 112), unc = 3, verbose = FALSE)
set.seed(42)
fit <- randomTest(az, nsims = 10, ncores = 1, .res = 2, verbose = FALSE)
plot(fit)
