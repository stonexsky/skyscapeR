Function index · jS() method

skyscapeR 2.0.9004

Estimate solar declination at the June solstice

Description

Estimate the limiting solar declination at the June solstice for comparison with a structural sightline.

Usage

jS(
  year = skyscapeR.env$cur.year,
  loc = FALSE,
  parallax = 0.00224,
  altitude = 0,
  verbose = TRUE
)

Arguments

year

Astronomical year. The default is the current year in the package settings. Historical labels such as "3700 BC" are accepted by astroYear.

loc

Latitude in degrees north or a skyscapeR.horizon object. Omit this argument or use FALSE for geocentric declination.

parallax

Mean horizontal parallax in degrees. The default is 0.00224 degrees for the Sun.

altitude

Altitude of the sun. Defaults to 0 degrees.

verbose

Logical to control output of warnings and messages. Defaults to TRUE.

Details

The June solstice is represented by the positive obliquity of the ecliptic for the requested epoch. The result is geocentric when no site is supplied. With a site, the function subtracts the approximate parallax correction using latitude and target altitude. This obliquity-based target does not determine a solstice time or a sunrise or sunset bearing.

Value

Numeric declination in degrees. With loc = FALSE the result is geocentric. Supplying a location applies the parallax correction for the chosen altitude.

See Also

obliquity, dS, eq, zenith, antizenith, spatial.equinox, parallax.corr

Examples

# June Solstice geocentric declination for year 4001 BC:
jS(-4000)

# Topocentric declination for same year and latitude of 50 degres N:
jS(-4000, loc=50)
