Function index · antizenith() method

Estimate solar declination at the anti-zenith

Description

Determine the solar declination associated with the point directly beneath an observer, where the Sun can attain that declination.

Usage

antizenith(loc, parallax = 0.00224, altitude = -90, year = skyscapeR.env$cur.year)

Arguments

loc

This can be either the latitude of the location, or a skyscapeR.horizon object.

parallax

Mean horizontal parallax in degrees. The default is 0.00224 degrees for the Sun.

altitude

Altitude used in the approximate parallax correction. Defaults to -90 degrees.

year

Astronomical year used to determine the tropical latitude limit.

Details

The direction opposite the zenith corresponds geometrically to minus the site latitude. The function checks the latitude against the obliquity of the requested epoch. At the geometric anti-zenith the altitude is minus 90 degrees and parallax vanishes. An explicitly supplied altitude invokes the approximate correction at that altitude. It returns NULL outside that band. This is a target declination for comparison with orientations, not an observable solar transit below ground.

Value

Solar declination in degrees with the requested parallax correction, or NULL when the latitude falls outside the solstitial limits used by the function.

Validation

A05 verified the geometric anti-zenith declination and tropical-boundary eligibility at two epochs. See the A05 check in the technical manual.

See Also

jS, dS, eq, zenith, spatial.equinox, parallax.corr

Examples

# Anti-zenith sun declination for Mexico City:
antizenith(19.419)

# The same location supplied as a horizon object:
hor <- createHor(c(0,90,180,270,360), c(0,2,1,3,0),
                 loc=c(19.419,-99.133,2240))
antizenith(hor)

# There is no anti-zenith solar phenomenon in London:
antizenith(51.507)
