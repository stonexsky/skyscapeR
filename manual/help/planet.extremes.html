Function index · planet.extremes() method

skyscapeR 2.0.9004

Extreme declinations for five visible planets

Description

Estimate the most northerly and southerly declinations reached by a visible planet near an archaeological epoch.

Usage

planet.extremes(obj, year, loc = NULL, epoch)

Arguments

obj

Planet name, with this capitalisation: Mercury, Venus, Mars, Jupiter or Saturn.

year

Year for which to do calculations. Historical labels such as "3700 BC" are accepted by astroYear.

loc

This can be either a skyscapeR.horizon object, or a vector with the latitude, longitude and elevation of the site, in this order.

epoch

Earlier argument name for year, retained for existing scripts.

Details

An epoch alone does not specify the planet's position in its cycle. The search extends three quarters of the package's planet-specific period on either side of the epoch, rounds the limiting years, and samples at daily intervals from noon UT on 1 January of the start year to the corresponding date in the end year. Each sample uses body.position and the requested site if supplied. The returned extrema are the range of these samples; finer extrema can fall between sampled instants.

Astronomical positions require Swiss Ephemeris files covering the epoch. We recommend installing swephRdata; see skyscapeR-package for setup.

Value

A list containing planet, min.dec and max.dec. The two declinations are extrema of daily samples and are expressed in degrees.

Provenance

Structured results carry a provenance attribute. Read it with attr(result, "provenance"); its packages entry records the loaded skyscapeR and swephR versions, with NA when a namespace version is unavailable. This attribute adds no list entries or table columns. Ordinary subsetting or transformations may discard attributes; save the original result for reference. It does not identify ephemeris files, catalogue revisions or a development commit. Retain those and the analysis script separately for exact reproduction.

See Also

spatial.equinox, zenith, antizenith, solar.date, findTargets, EFM

Examples

## Not run: 
# Searches across multiple planetary cycles; may take more than five seconds.
if (requireNamespace("swephRdata", quietly = TRUE)) {
  planet.extremes('Jupiter', 2023)
  
  planet.extremes('Venus', "4001 BC")
}

## End(Not run)
