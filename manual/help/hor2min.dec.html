Function index · hor2min.dec() method

skyscapeR 2.0.9004

Find the southern declination limit of a horizon

Description

Estimate the smallest declination indicated by the horizon near true south.

Usage

hor2min.dec(hor, alt = 0, range = 25)

Arguments

hor

Either a skyscapeR.horizon object or the latitude of the place.

alt

Altitude of the horizon at southernmost point. Only necessary if no skyscapeR.horizon object is provided. Default is 0.

range

Range of azimuths to check for minimum declination. Default is 25 degrees either side of South

Details

Terrain relief can shift the limiting sightline away from the meridian. The function samples bearings at 0.01-degree spacing within the specified half-width around 180 degrees. It calls az2dec at each bearing with the stored horizon, or with the supplied latitude and constant altitude, then returns the minimum sampled declination. A limited search sector may miss a more extreme sightline elsewhere.

Value

One numeric value in degrees, the smallest declination sampled across the specified azimuth range around south.

Examples

hor <- malta_horizons[[1]]
hor2min.dec(hor)
