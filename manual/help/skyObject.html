skyscapeR 2.0.9004

Prepare celestial targets for orientation plots

Description

Define celestial targets and their declinations so the same hypotheses can be overlaid on several orientation plots.

Usage

skyObject(names, year, loc = FALSE, col = "#A9542E", lty = 1, lwd = 1, epoch)

sky.objects(names, year, loc = FALSE, col = "#A9542E", lty = 1, lwd = 1, epoch)

Arguments

names

Target names, star names or custom declinations in degrees. Use "solar extremes" for the solstices or "lunar extremes" for the four lunar extremes.

year

An astronomical year or a pair of year endpoints. Historical labels such as "3700 BC" are accepted by astroYear.

loc

This can be either a vector with the latitude and longitude of the location, or a skyscapeR.horizon object.

col

The color for plotting, and differentiating these objects. Defaults to ochre for all objects.

lty

Line type (see par) used for differentiation. Used for single-year tracks and year-range boundaries.

lwd

Line width (see par) used for differentiation. Used for single-year tracks and year-range boundaries.

epoch

Earlier argument name for year, retained for existing scripts.

Details

An overlay identifies which targets to compare before inspecting a distribution. Names may denote stars, solar or lunar limits, or fixed custom declinations. Group names expand into the individual limits. At one epoch, the function evaluates each target; for two endpoints it uses annual January stellar declinations. Solar and lunar limits retain century-spaced samples and spline interpolation. Styles and epoch travel with the object. Treat range endpoints as model estimates and verify narrow or rapidly changing windows separately. A single object can contain several related targets. Pass a list of objects to plot(hor), plotBars or plotAzimuth to combine groups with independent epochs, colours, line styles and labels. Groups are drawn in list order. Horizon plots use the plotted horizon's location for every track. Compass plots use each group's stored location and a level horizon, drawing both declination boundaries for a year-range group. Declination plots need no location. No common epoch range is imposed and no astronomical positions are recomputed merely by combining objects. The output class remains skyscapeR.object, so previously saved objects remain usable. sky.objects is a silent compatibility alias for skyObject.

Value

A skyscapeR.object list. Columns of decs represent targets, in degrees. A single epoch produces one row. For a two-year range the rows are labelled min and max. The other fields record target count, epoch, location and plotting styles.

A reference track is not a dated orbit

Each target represents a declination or declination range. A plotted track holds that declination fixed while hour angle varies. It does not follow the changing declination of a moving Solar System body through a particular day. In particular, skyObject("Equinox", year) is an equinox reference; the Sun at sunrise or sunset on the equinox date need not lie at the same declination as at the equinox instant. A small offset from a solar disc in sketchSky can therefore be expected.

To compare with a particular instant, obtain its declination with body.position using the intended coordinate frame, and pass that numeric value to skyObject. Even that fixed-declination track is an approximation to a moving body's full daily orbit. Refraction and the plotted site's coordinates are applied when drawing the horizon track.

Provenance

Structured results carry a provenance attribute. Read it with attr(result, "provenance"); its packages entry records the loaded skyscapeR and swephR versions, with NA when a namespace version is unavailable. This attribute adds no list entries or table columns. Ordinary subsetting or transformations may discard attributes; save the original result for reference. It does not identify ephemeris files, catalogue revisions or a development commit. Retain those and the analysis script separately for exact reproduction.

Examples

# Create an object with solar targets for epoch range 4001-2001 BC:
tt <- skyObject('solar extremes', c("4001 BC", "2001 BC"))

if (requireNamespace("swephRdata", quietly=TRUE)) {
# Create an object with a few stars for same epoch:
tt <- skyObject(c('Sirius', 'Betelgeuse', 'Antares'), c("4001 BC", "2001 BC"),
col=c('white', 'red', 'orange'))
}

# Create an object with solstices and a custom declination value:
tt <- skyObject(c('December Solstice','June Solstice', -13), c("4001 BC", "2001 BC"))
# Mix a single-epoch group with a range, preserving each group's styles:
groups <- list(skyObject(12, "2001 BC", col="blue"),
               skyObject("solar extremes", c("4001 BC", "2001 BC"), col="orange"))
plotBars(c(-24,12,24), unc=1, obj=groups)
