Function index · solar.date() method

Find dates when the Sun reaches a specified declination

Description

Estimate the dates on which the Sun could attain a declination indicated by a structure in a selected year.

Usage

solar.date(dec, year, calendar, verbose = TRUE)

Arguments

dec

One or more declinations in degrees.

year

Year for which to do calculations. Historical labels such as "3700 BC" are accepted by astroYear.

calendar

Calendar for sampling and output. G for Gregorian or J for Julian. Defaults to the package calendar, initially Gregorian.

verbose

Logical. Display progress or informational messages. Default TRUE.

Details

The Sun can pass the same declination on either side of a solstice. The search covers the selected civil year from midnight UT, including its first instant and excluding the start of the next year. Daily geocentric apparent solar declinations bracket the annual turning points. The function refines each extremum against the ephemeris and solves separately on either side, then reports the civil day of each crossing. A tangency gives one date. Two crossings can share a calendar day. The calculation uses no terrain or solar limb model.

Astronomical positions require Swiss Ephemeris files covering the epoch. We recommend installing swephRdata; see skyscapeR-package for setup.

Value

A character matrix with one column per reachable input, in input order. The rows are Dec, Date1 and Date2, with Date3 added if three passages fall in one civil year. Dates are chronological day/month labels. Unused date cells are missing. The function stops if all requested declinations are unreachable.

Provenance

Structured results carry a provenance attribute. Read it with attr(result, "provenance"); its packages entry records the loaded skyscapeR and swephR versions, with NA when a namespace version is unavailable. This attribute adds no list entries or table columns. Ordinary subsetting or transformations may discard attributes; save the original result for reference. It does not identify ephemeris files, catalogue revisions or a development commit. Retain those and the analysis script separately for exact reproduction.

Validation

The JPL comparison in A05 matched all tested civil-day passages, including paired dates near a solstice. See the A05 check in the technical manual.

See Also

Examples

if (requireNamespace("swephRdata", quietly = TRUE)) {
  solar.date(-23, 2018)
  solar.date(-12, 1200, calendar='G')
  solar.date(-12, 1200, calendar='J')
  solar.date(14, -2000)
}
