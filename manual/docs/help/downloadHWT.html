Download a horizon from a HeyWhatsThat panorama

Description

Recover an existing terrain-derived horizon for use in site-specific orientation calculations.

Usage

downloadHWT(HWTID)

Arguments

HWTID

This is the 8 character ID attributed by HeyWhatsThat.com

Details

A panorama describes the horizon seen from a particular observer location. The optional httr2 package retrieves site metadata and 0.125-degree horizon bins over HTTPS. Site elevation above sea level is reported in metres, converting feet when necessary. Validated profiles are cached by panorama identifier for the R session. Read-only downloads allow up to three attempts for transient HTTP failures, with a 30-second limit per request. For each bin, the distance and angular altitude determine a height difference. The mean angular change for height offsets of plus and minus 9.73 metres estimates altitude uncertainty.

Value

A skyscapeR.horizon list containing site metadata and horizon samples. The data columns az, alt and alt.unc are in degrees. Retrieval requires access to the HeyWhatsThat service.
