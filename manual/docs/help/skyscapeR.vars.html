Function index · skyscapeR.vars() method

skyscapeR 2.0.9004

Inspect or set session defaults for skyscapeR

Description

Set the observing and time conventions that should be shared across an analysis, or retrieve them for a reproducible methods record.

Usage

skyscapeR.vars(timezone, calendar, refraction, atm, temp, dec, k)

Arguments

timezone

Timezone name (for example "Europe/London") or fixed offset in hours east of UTC, or a string such as "UTC+02:00". Initially "Europe/London". Use UTC or a fixed offset for dates before 1900. See time2jd for details.

calendar

Calendar for civil dates. Use "G" for Gregorian or "J" for Julian.

refraction

Whether atmospheric refraction is to be taken into account. Default is TRUE.

atm

Air pressure in mbar for the refraction calculation. Default is 1013.25 mbar.

temp

Air temperature in degrees Celsius for the refraction calculation. Default is 15 degrees Celsius.

dec

Output declination: geo for the geocentric, or topo for the topocentric frame of reference. Defaults to topocentric.

k

Visual extinction in magnitudes per airmass, shared by natural sky sketches and stellar phase calculations. The initial value of 0.2 is a clear-sky baseline, consistent with the approximate V-band coefficient for Kitt Peak in the UC Davis Physics 157 Observing Guide. Extinction varies with site and atmospheric conditions (Schaefer 1986, 1993). Use zero to disable extinction.

Details

The same observation can have different labels or apparent coordinates under different calendar, timezone, reference-frame or atmospheric choices. With no arguments the function returns a named snapshot. Supplied arguments update the package environment for subsequent calls in the current R session. Functions with their own explicit arguments or fixed UT sampling conventions may override these defaults. Record the settings with the survey data.

Value

A named list of the current session settings, including the current year. Supplying an argument updates that setting for subsequent package calls in this R session.
