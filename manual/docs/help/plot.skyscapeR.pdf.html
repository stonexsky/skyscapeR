Function index · plot.skyscapeR.pdf() method

Plot orientation probability distributions

Description

Compare the uncertainty distributions of individual orientations or examine how a single sightline was transformed to declination.

Usage

## S3 method for class 'skyscapeR.pdf'
plot(
  x,
  index,
  hdr = 0.954,
  show.az,
  xrange,
  col = NULL,
  ...,
  az,
  hor,
  xlim,
  show.legend = TRUE,
  style = "publication-colour"
)

Arguments

x

A skyscapeR.pdf object created with either az.pdf or coordtrans

index

A value to indicate which distribution to plot, when only one is desired.

hdr

High density region to highlight. Defaults to 0.954

show.az

Deprecated and ignored, with a warning when supplied. Provide both az and hor for the combined panels, or omit both for distributions alone.

xrange

Range of x-axis to plot.

col

Fill colour for highest-density regions. NULL uses the current style.

...

Additional arguments to be passed to plot.

az

Original azimuth skyscapeR.pdf, in the same order and with the same number of distributions as x. Supply together with hor to show combined panels for a single declination distribution.

hor

Original horizon object, or a list of horizons in the same order and with the same length as the distributions in x. Supply with az.

xlim

Earlier name for xrange.

show.legend

Show the HDR mass above stacked densities. The linked diagnostic always identifies its component panels and reports the numerical interval or intervals.

style

Analytical display style, either "publication-colour" (default) or "publication-mono". Monochrome uses grayscale and preserves line styles.

Details

Individual curves reveal whether measurements overlap or have disjoint high-density regions. In the stacked view, each selected density is scaled by its own peak for display and its highest-density regions are shaded using hpdi. Heights across different rows therefore do not measure relative probability mass. Use the linked panels for one transformed observation to inspect how its source azimuth distribution and horizon produce the declination distribution. Its annotation gives the measurement name and the highest-density declination interval or intervals containing the requested probability mass. Every disjoint component is listed in the HDR readout. Standalone curves have a fixed label column.

With neither source input supplied, plot the distributions alone. With both az and hor, show the information, azimuth, transformation and declination panels. A single index is required for combined panels. Supplying only one source input is an error, as is supplying source inputs for an azimuth distribution. Source inputs must be named explicitly.

Supply the original sources in measurement order. Counts and structure are checked, but the function cannot verify their identity. The transformation curve uses the refraction, pressure and temperature recorded with the result.

Value

Draws the selected probability distributions and requested intervals on the active graphics device.

Validation

In W01 the shaded components matched the two intervals returned by hpdi() for a bimodal density. See the W01 check in the technical manual.

See Also

az.pdf, dec.pdf, coordtrans, hpdi

Examples

Az <- az.pdf(az=c(87,93), unc=3, verbose=FALSE)
hor <- createHor(c(0,360), c(2,2), loc=c(35,-8,25))
Dec <- coordtrans(Az, hor, verbose=FALSE)
plot(Dec)
plot(Dec, index=1, az=Az, hor=hor)
