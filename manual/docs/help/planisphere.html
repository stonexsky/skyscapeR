Function index · planisphere() method

skyscapeR 2.0.9004

Draw a planisphere for a site and epoch

Description

Map the stars that can enter a site's sky at a chosen epoch, with the celestial equator and ecliptic as optional references.

Usage

planisphere(
  year,
  lat,
  max.mag = 6,
  show.ecliptic = TRUE,
  col.ecliptic = "#A9542E",
  show.equator = TRUE,
  col.equator = "#597575",
  star.col = "#23383A",
  epoch,
  show.milky.way = TRUE,
  show.galactic.equator = FALSE,
  constellations = NULL,
  col.constellations = "#638582",
  show.legend = TRUE,
  style = "publication-colour"
)

Arguments

year

The epoch (year) for which the planisphere is calculated. Historical labels such as "3700 BC" are accepted by astroYear.

lat

Observer latitude in degrees north, between -90 and 90.

max.mag

Faintest catalogue magnitude drawn as a star symbol (default 6). This does not filter constellation line endpoints.

show.ecliptic

Whether to display the ecliptic (TRUE or FALSE).

col.ecliptic

Colour of the ecliptic line (default ochre).

show.equator

Whether to display the celestial equator (TRUE or FALSE).

col.equator

Colour of the celestial equator (default muted grey-green).

star.col

Colour of the star symbols (default dark grey-green).

epoch

Earlier argument name for year, retained for existing scripts.

show.milky.way

Draw the Milky Way behind the stars (default TRUE). Set to FALSE for a chart without the band.

show.galactic.equator

Draw the Galactic equator as a dash-dot line. Default FALSE.

constellations

Optional constellation selection: a bundled set such as "modern", "chinese" or "chinese_mansions", figure names or identifiers, or a table from importConstellations. The default NULL draws no constellation lines.

col.constellations

Colour of the constellation lines (default muted teal).

show.legend

Show chart pole, latitude, epoch, magnitude limit and the enabled layer key. FALSE centres the bare chart, keeping its data and right-ascension ticks.

style

Analytical display style, either "publication-colour" (default) or "publication-mono". Monochrome uses grayscale and preserves line styles.

Details

The default star layer draws individual Pleiades members and omits integrated clusters and other nonstellar entries. The full catalogue remains available for target searches and phase calculations.

The chart compares the accessible part of the celestial sphere with a catalogue sky at the chosen year. Catalogue stars are filtered by magnitude and by the implemented declinations that rise above a level geometric horizon. Northern latitudes use the north celestial pole; southern latitudes use the south celestial pole. Polar distance sets radius, and right ascension sets angle with opposite handedness for the two poles. Magnitude controls symbol size, and hour labels are placed every three hours. The optional ecliptic uses daily solar positions over a year, using geocentric coordinates without atmospheric refraction. The plot is not an instantaneous view through a site's measured horizon. The Milky Way uses the same diffuse-light tracing as sketchSky(), with dark cutouts and two brighter tiers referenced to the whole-band mean. Source: NASA/Goddard SVS and ESA/Gaia/DPAC, Deep Star Maps 2020. It is a fixed sky map rotated to the requested epoch with Swiss Ephemeris precession and nutation. Its width is illustrative. It does not predict visibility or reconstruct the Galaxy’s internal evolution.

Astronomical positions require Swiss Ephemeris files covering the epoch. We recommend installing swephRdata; see skyscapeR-package for setup.

Value

Draws the polar chart on the active graphics device and invisibly returns the saved xpd, mar and pty graphics settings.

Constellation patterns

Constellation segments follow the shorter great-circle arc between catalogue endpoints at the requested epoch. They use the same polar projection as the stars and are clipped to the chart's accessible sky. Faint endpoints remain available for line drawing even when no star symbol is shown. Missing catalogue endpoints generate a warning and their segments are omitted. These are line figures; repeated endpoints mark single-star figures with small rings. They are not constellation boundaries or lunar-mansion sectors. See constellations for sources, licences and historical limitations.

Projection and visibility limits

This is a polar azimuthal equidistant chart. For latitude at or above zero, radius is 90 minus declination and right ascension increases clockwise from the top. For negative latitude, radius is 90 plus declination and right ascension increases anticlockwise. The chart radius is 180 minus absolute latitude; a non-round cutoff is retained exactly. All layers use this same projection. At the equator the north-polar convention is used.

Stars are included when their upper culmination is strictly above a level geometric horizon; stars that only touch it are excluded. This is potential annual access to that part of the sky, not visibility at any particular time. There is no date/time of night, local terrain, atmospheric extinction, moonlight or twilight detection model. Magnitudes are fixed catalogue values, and point size is a graphical brightness indicator. For a particular site and instant use sketchSky with a georeferenced horizon.
