Function index · star() method

skyscapeR 2.0.9004

Calculate a fixed star's coordinates for an epoch

Description

Find a catalogue object's equatorial position at an archaeological epoch and its apparent magnitude for a sky or visibility model.

Usage

star(string, year = skyscapeR.env$cur.year)

Arguments

string

This can be either the traditional name for the star or its Bayer designation.

year

Year for which to calculate the coordinates. Historical labels such as "3700 BC" are accepted by astroYear. Defaults to current year.

Details

A historical comparison requires a stellar coordinate for the epoch under study. The function resolves a Western common name through star.names or accepts a catalogue identifier and checks it against Swiss Ephemeris. It evaluates equatorial coordinates at noon UT on 1 January of each supplied astronomical year in the Gregorian calendar. The magnitude is a catalogue value. These outputs can feed horizon transformations or visibility estimates, which additionally require observer and atmosphere information.

The Swiss Ephemeris manual documents fixed-star positions and catalogue magnitudes.

Astronomical positions require Swiss Ephemeris files covering the epoch. We recommend installing swephRdata; see skyscapeR-package for setup.

Value

A skyscapeR.star list with name, Bayer designation, apparent magnitude (app.mag) and a coord data frame. Each row contains year, right ascension (RA) and declination (Dec), both angles in degrees.

Provenance

Structured results carry a provenance attribute. Read it with attr(result, "provenance"); its packages entry records the loaded skyscapeR and swephR versions, with NA when a namespace version is unavailable. This attribute adds no list entries or table columns. Ordinary subsetting or transformations may discard attributes; save the original result for reference. It does not identify ephemeris files, catalogue revisions or a development commit. Retain those and the analysis script separately for exact reproduction.

References

Astrodienst. Swiss Ephemeris programmer's manual. https://www.astro.com/swisseph/swephprg.htm.

See Also

swe_fixstar2_ut, swe_fixstar2_mag, star.names, star.phases

Examples

# M45 and M 45 identify the Pleiades.
if (requireNamespace("swephRdata", quietly=TRUE)) star("M45", -4300)

if (requireNamespace("swephRdata", quietly = TRUE)) {
  # Retrieve data for Aldebaran:
  Aldeb <- star('Aldebaran')
  
  # Retrieve data for Aldebaran on 3001 BC:
  ss <- star('Aldebaran', -3000)
}
