Function index · obliquity() method

Calculate the obliquity of the ecliptic

Description

Estimate the tilt of the ecliptic at a proposed epoch to set solar and lunar declination limits.

Usage

obliquity(year = skyscapeR.env$cur.year)

Arguments

year

Year for which to calculate the obliquity. Historical labels such as "3700 BC" are accepted by astroYear. Defaults to present year as given by Sys.Date

Details

The tilt changes over archaeological timescales. For each supplied astronomical year the calculation uses Gregorian 1 January at noon UT, requests the obliquity/nutation record from Swiss Ephemeris and returns its first element, the true obliquity in degrees. An annual value is a reference for limiting declinations rather than a search for the instant of solstice.

Value

Numeric obliquity of the ecliptic in degrees, one value per astronomical year.

Validation

A05 checked the January true obliquity at modern and prehistoric test epochs against direct engine values. See the A05 check in the technical manual.

References

Laskar, J. et al. (2004), A long-term numerical solution for the insolation quantities of the Earth, Astron. Astroph., 428, 261-285, doi:10.1051/0004-6361:20041335.

See Also

swe_calc_ut, jS, dS

Examples

# Obliquity for year 4001 BC:
obliquity("4001 BC")
