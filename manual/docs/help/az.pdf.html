skyscapeR 2.0.9004

Represent measured azimuths as probability densities

Description

Represent uncertainty in a measured orientation before comparing it with other bearings or transforming it to declination.

Usage

az.pdf(
  az,
  unc,
  pdf = "normal",
  name,
  .res = 0.01,
  .cutoff = 1e-05,
  verbose = T
)

Arguments

az

True bearings in degrees clockwise from north, one per observation.

unc

Angular uncertainty in degrees, one value shared across observations or one per azimuth. For a normal distribution this is the standard deviation. For a uniform distribution it is the half-width on either side of the measurement.

pdf

Uncertainty distribution. Choose "normal" (default) or "uniform".

name

Optional labels in the same order as the measurements.

.res

Spacing of the output bearing grid in degrees. Default 0.01.

.cutoff

Minimum density retained on the output grid. Default 1e-5.

verbose

Logical. Display progress or informational messages. Default TRUE.

Details

A field bearing defines a centre and an angular uncertainty. Model the uncertainty as a normal density with the supplied standard deviation, or as a uniform density over the centre plus or minus the supplied half-width. A scalar uncertainty is reused for each measurement. The function samples from -90 to 450 degrees, folds the overlapping tails across north and retains density values at or above the cutoff. Use a spacing compatible with a full turn on the grid. The input measurements remain separate and truncated tails are not renormalised. The supported families are normal and uniform.

Value

A skyscapeR.pdf list. The data component contains one data frame per measurement, in input order, with azimuth x in degrees and density y. The metadata record the measurements, names, uncertainties, distribution type and numerical settings.

References
