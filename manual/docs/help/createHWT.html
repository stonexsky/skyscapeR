Request a HeyWhatsThat panorama and retrieve its horizon

Description

Request a terrain-derived horizon for an observing site when comparing orientations with possible rising or setting directions.

Usage

createHWT(
  lat,
  lon,
  name,
  elevation = 1.6,
  src = "skyscapeR",
  max.wait = 600,
  verbose = TRUE
)

Arguments

lat

The latitude of the location.

lon

The longitude of the location.

name

Name assigned to the returned horizon profile.

elevation

The elevation of the observer above ground level in meters. Default is 1.6 meters (eye level).

src

Request source ID for HeyWhatsThat. Default is 'skyscapeR'. Only change this if you have been given a source ID by the creator of HeyWhatsThat.

max.wait

Maximum seconds to wait for panorama readiness after submission. Default 600.

verbose

Logical switch to control output. Default is TRUE.

Details

A digital horizon supplies estimated angular obstruction around the site. The optional httr2 package submits one HTTPS request for a panorama. Once the service returns its identifier, the function waits two minutes before the first readiness check, then polls at intervals of up to 15 seconds. The polling deadline defaults to 600 seconds. If the wait expires, use the identifier with downloadHWT once the panorama is ready. Individual requests have a timeout of at most 30 seconds. The initial submission and final download are separate from the polling time allowance. Once ready, the profile is downloaded and assigned the supplied name. Terrain-derived profiles need field verification where vegetation or structures affect visibility.

Value

A skyscapeR.horizon object for the requested panorama, as returned by downloadHWT. This function submits a remote request and waits for the calculated profile.
