Function index · dec.pdf() method

skyscapeR 2.0.9006

Represent measured declinations as probability densities

Description

Represent the uncertainty of directly supplied declinations so they can be summed or tested against a declination model.

Usage

dec.pdf(
  dec,
  unc,
  pdf = "normal",
  name,
  .res = 0.01,
  .cutoff = 1e-04,
  verbose = TRUE
)

Arguments

dec

Measured declinations in degrees, between -90 and 90 inclusive.

unc

Positive uncertainties in degrees of declination. Supply one value or one per measurement. For normal densities this is the standard deviation. For uniform densities it is the half-width.

pdf

Distribution family, "normal" or "uniform", with the same abbreviations as az.pdf.

name

Optional measurement labels in input order.

.res

Grid spacing in degrees. Default 0.01.

.cutoff

Minimum retained density height. Default 0.0001.

verbose

Logical. Report completion.

Details

A declination estimate already incorporates the sightline geometry. This constructor works directly in that coordinate. For each centre it evaluates a normal density with the given standard deviation or a uniform density with the given half-width. A single uncertainty is shared, or one can be supplied per observation. Save the original uncertainty interpretation when comparing results from different surveys.

Each grid is restricted to physical declinations and trimmed at .cutoff. The retained curve is not renormalised after truncation. Use spd to combine measurements.

Silva (2020) sets out the probability-distribution framework for uncertain orientations. Here the supplied measurements and uncertainties are already expressed in declination.

Value

A skyscapeR.pdf list with one x/y data frame per observation. Metadata record coord = "dec", the input measurements, family, uncertainties, labels and numerical settings.

Validation

In D01, sampled declination densities agreed with analytic references. Build 2.0.9006 retained the corresponding declination centres in all four subset checks. See D01 validation in the technical manual.

References

Silva, F. (2020). A probabilistic framework and significance test for the analysis of structural orientations in skyscape archaeology. Journal of Archaeological Science 118, 105138. \Sexpr[results=rd]{tools:::Rd_expr_doi("10.1016/j.jas.2020.105138")}.
