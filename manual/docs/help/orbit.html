Function index · orbit() method

Trace the path of a celestial body at a site

Description

Trace the daily path of a fixed declination across the sky as seen from a site.

Usage

orbit(dec, loc, refraction, atm, temp, res = 0.25)

Arguments

dec

Declination of object.

loc

Location, either a skyscapeR.horizon or a vector containing the latitude and longitude of location, in this order.

refraction

Logical. Apply atmospheric refraction. Defaults to the session setting in skyscapeR.vars.

atm

Atmospheric pressure in mbar. Defaults to the session setting in skyscapeR.vars.

temp

Air temperature in degrees Celsius. Defaults to the session setting in skyscapeR.vars.

res

The resolution (in degrees of RA) with which to calculate the path.

Details

Latitude and declination determine where a diurnal track can meet the terrain. The function sweeps equatorial right ascension through 360 degrees at the requested angular step and converts each position to horizontal coordinates with the selected refraction and atmosphere settings. It retains altitudes above -20 degrees and sorts the points by azimuth. A horizon object supplies the location; the stored track itself includes no test of terrain obstruction or event times.

Value

A skyscapeR.orbit list with az and alt vectors in degrees, ordered by azimuth, plus the input declination (dec) and location (georef). The sampled track retains altitudes above -20 degrees.

Provenance

Structured results carry a provenance attribute. Read it with attr(result, "provenance"); its packages entry records the loaded skyscapeR and swephR versions, with NA when a namespace version is unavailable. This attribute adds no list entries or table columns. Ordinary subsetting or transformations may discard attributes; save the original result for reference. It does not identify ephemeris files, catalogue revisions or a development commit. Retain those and the analysis script separately for exact reproduction.

Validation

In A08, coordinates on the two plotted solar-limit tracks recovered their source declinations by spherical inversion. See the A08 check in the technical manual.

See Also

plotAzimuth, plotBars, sketchSky, planisphere

Examples

# Visible path of sun on june solstice on year 4001 BC from London:
sun.dec <- jS(-4000)
london.lat <- 51.5074 #N
london.lon <- -0.1278 #W
loc <- c( london.lat, london.lon, 0 )
path <- orbit(sun.dec, loc)
plot(path$az, path$alt, ylim=c(0,90), type='l', xlab='AZ', ylab='ALT', col='red', lwd=2)
