Function index · sketchSky() method

Prepare a reusable sky sketch for a horizon plot

Description

Calculate the sky above one observing site at one instant, then reuse it as the background of a horizon plot. Natural style illustrates daylight, twilight, moonlight and atmospheric extinction. Publication styles show the selected objects without brightness-dependent visibility filtering.

Usage

sketchSky(
  hor,
  jd = NULL,
  time = NULL,
  timezone,
  calendar,
  display = list(),
  style = c("natural", "publication-colour", "publication-mono"),
  max.mag = 6,
  k = skyscapeR.vars()$k
)

Arguments

hor

A skyscapeR.horizon with finite latitude, longitude and observer elevation in metres in metadata$georef. The numerical profile supplies the foreground when plotted. A panorama image is optional.

jd

One finite UT Julian day. Supply exactly one of jd and time.

time

A civil timestamp accepted by time2jd, or a POSIXt instant.

timezone, calendar

Civil timezone and calendar for character time, as in time2jd. Defaults are the session settings. A POSIXt value already identifies an instant; these arguments do not reinterpret it. Use UTC or a fixed offset for ancient civil dates.

display

A named list of logical switches: sun, moon, planets, stars, constellation.lines, milky.way, galactic.equator, ecliptic, equator, poles and zenith. Sun, Moon and stars default to TRUE; other switches default to FALSE, except that the Milky Way follows stars unless explicitly set. The additional constellations entry accepts names or an imported data frame, rather than a logical value. See Constellations below. A named logical vector is sufficient when supplying only switches.

style

One of "natural", "publication-colour" or "publication-mono". Publication styles have a white background and dark guides. Colour uses muted stellar and planetary colours and a warm solar disc; mono uses black and white. Neither publication style predicts visibility.

max.mag

Finite catalogue magnitude cutoff, default 6. Applied before extinction to star symbols and the integrated magnitudes of supported clusters. It does not limit constellation endpoints, the Sun, Moon or planets. Raising the cutoff includes additional stars only where the catalogue supplies them.

k

Non-negative visual extinction coefficient in magnitudes per airmass for natural style. Defaults to skyscapeR.vars()$k, initially 0.2. This clear-sky baseline is an assumption, not an estimate of the site's weather. Zero removes extinction and the modelled lunar scattering. Publication styles do not apply extinction to symbols.

Details

The function computes an object without drawing. Use plot(hor, sky = sky, xrange = ..., yrange = ...) to choose the sector. Replotting the object changes framing without recalculating the instant. Use skyStep to recalculate at another time. Astronomical calculations require Swiss Ephemeris files covering the epoch; see skyscapeR-package for installation.

Value

An object of classes skyscapeR.sketch and skyscapeR.sky. It stores jd, loc, style, display, settings (calendar, magnitude cutoff and extinction), and atmosphere. stars and coords contain azimuth, altitude and symbol size; star.opacity retains an earlier symbol-opacity diagnostic; natural sketches draw from light.budget. bodies, diameters, planet.size and lunar describe selected Solar System bodies. clusters holds supported cluster footprints and opacity when applicable. The natural view uses the integrated Pleiades magnitude as the light budget within its projected footprint. When the plotted stars exceed that budget, their fluxes are scaled together to preserve their relative brightness. Any residual light uses a broad, tapered profile; guides, light, background and twilight fields support drawing. Components can be empty when a layer is disabled. No image file is written.

Reading a natural sketch

The sky is calculated for the specified instant. Stars, clusters, planets and the Moon contribute light on a common visual (V-band) magnitude scale. Diffuse Milky Way light and atmospheric background are measured per unit sky area. Their light is added before brightness is compressed for display. To inspect the values underlying a view, use skyRadiance.

Stars remain unresolved as the field is enlarged. Mercury, Venus, Mars, Jupiter, Saturn and the Moon use apparent disc sizes and illuminated fractions from Swiss Ephemeris. A close view can therefore show the phase of Venus. Star colours follow catalogue spectral classes; the diffuse band has a neutral tint. Colour and projection influence the screen appearance. Publication styles use magnitude-scaled star and planet symbols on white. In publication colour, stellar hue identifies the leading catalogue spectral class O through M; other or missing classes use neutral grey.

Azimuth increases clockwise from true north. Refraction, pressure and temperature come from skyscapeR.vars when the sky is calculated. The Sun and Moon switches control their contributions to sky illumination as well as their discs. Use display = list(moon = FALSE) for a moonless comparison. The terrain masks the drawn sky; a local ridge hiding the Moon can still leave scattered moonlight in the sky.

Constellations

Use display = list(constellations = "Orion") to select and enable line figures. "modern" selects all 88 Western figures, "chinese" the full Chinese set, and "chinese_mansions" the 28 lunar-mansion figures. Names and abbreviations are case-sensitive; for example c("Ori", "Tau"). Alternatively, supply a data frame from importConstellations. See constellations for sources and identifiers.

Supplying a selection enables lines unless constellation.lines = FALSE is also supplied. Setting constellation.lines = TRUE without a selection uses modern figures. Endpoint coordinates are calculated independently of the star-symbol magnitude cut. Lines therefore remain when their stars are faint, extincted, or switched off. A single-star figure is drawn as a ring. Normal plot clipping and the horizon foreground still apply. These are reference figures; their visibility is not an observing prediction.

Twilight and extinction

At twilight the sky brightens differently towards and away from the Sun. Zenith brightness uses the Paranal V-band observations of Patat et al. (2006) at solar depressions of 5 to 15 degrees. Sacramento Peak measurements supply earlier twilight levels and the directional variation (Koomen et al. 1952). These clear-sky estimates depend on site conditions. Moonlight uses the scattering model of Krisciunas and Schaefer (1991), with its dependence on lunar phase, altitude and angular separation.

Direct light fades towards the horizon as its path through the atmosphere lengthens. The coefficient k sets the loss per airmass. The model uses Rozenberg's airmass approximation (Krisciunas and Schaefer 1991); uncertainty is greatest close to the skyline. The twilight colours are illustrative (Lee 1994, 2015).

Milky Way and clusters

The Milky Way is traced from the diffuse light in Deep Star Maps 2020. Within the smoothed envelope, retained dark patches have at least 10 percent local contrast; two bright tiers begin at 1.10 and 1.75 times the mean band tone after the dark patches are excluded. Retained patches cover at least 10 square degrees. Natural sketches anchor the mean surface brightness of a four-degree field in Carina to 20.7 V magnitudes per square arcsecond (van der Kruit 2024). Brightness elsewhere is approximate. Atmospheric extinction can make the band difficult to follow down to its calculated horizon crossing. The Galactic equator is an optional geometric guide.

A supported cluster contributes its catalogue light across its angular extent. Light already assigned to plotted stars within that footprint is subtracted before the remaining glow is drawn. This accounts for projected overlap; it does not establish membership. Integrated cluster magnitude alone is insufficient to predict first detection (Crumey 2014).

Using a sketch with a stellar phase date

In 69 of 70 individual comparisons, the estimated first morning of visibility was within a week of the predicted heliacal-rising date.

Use riseset to locate the skyline crossing on each morning, then skyStep to follow the star as it climbs through a brightening sky. A plotted pixel does not establish naked-eye visibility. A quantitative test needs a point-source threshold and an assumed observer limit (Crumey 2014). See also star.phases. Record site, horizon, epoch, calendar, timezone, extinction and display switches when reporting a reconstruction.

Provenance

Structured results carry a provenance attribute. Read it with attr(result, "provenance"); its packages entry records the loaded skyscapeR and swephR versions, with NA when a namespace version is unavailable. This attribute adds no list entries or table columns. Ordinary subsetting or transformations may discard attributes; save the original result for reference. It does not identify ephemeris files, catalogue revisions or a development commit. Retain those and the analysis script separately for exact reproduction.

Validation

W02 verified the reconstructed Gacrux bearing and altitude at the same instant and viewpoint using direct equatorial coordinates and spherical geometry. See the W02 check in the technical manual.

Examples

## Not run: 
hor <- malta_horizons[[1]]
sector <- c(0, 180)
sky <- sketchSky(hor, time = "2026/12/21 20:00", timezone = "UTC")
plot(hor, sky = sky, xrange = sector)
sky <- skyStep(hor, sky, minutes = 10, xrange = sector)

# Compare publication styles at exactly the same instant.
colour <- sketchSky(hor, jd = sky$jd, style = "publication-colour",
                    display = list(constellations = "modern"))
mono <- sketchSky(hor, jd = sky$jd, style = "publication-mono",
                  display = list(constellations = "modern"))
plot(hor, sky = colour, xrange = sector)
plot(hor, sky = mono, xrange = sector)
