Export a site horizon as a Stellarium landscape

Description

Reproduce a measured or modelled archaeological horizon as a Stellarium landscape for visual comparison.

Usage

exportHor(
  hor,
  name,
  author = "skyscapeR",
  description,
  use.image = TRUE,
  peakfinder.layout = c("single", "native"),
  max.texture.width = 4096,
  ground_col,
  hor_col
)

exportStellarium(
  hor,
  name,
  author = "skyscapeR",
  description,
  use.image = TRUE,
  peakfinder.layout = c("single", "native"),
  max.texture.width = 4096,
  ground_col,
  hor_col
)

Arguments

hor

Horizon data in skyscapeR.horizon format.

name

Horizon name to be displayed in Stellarium, if different from one in skyscapeR.horizon object.

author

Author, to be included in landscape.ini file.

description

Description, to be included in landscape.ini file.

use.image

Include a valid external panorama PNG when available. Default TRUE. Missing or changed files warn and use a polygonal horizon instead.

peakfinder.layout

Single spherical PNG (default) or original native tiles. Textured DEM and PeakFinder exports use their PNG silhouette.

max.texture.width

Maximum exported DEM or photographic panorama width in pixels. The default is 4096. Use max.texture.width=2048 for a smaller texture, or Inf to keep the original dimensions. Stellarium supports textures only up to the graphics hardware limit. PNG compression does not reduce the decoded texture dimensions. Larger exports are at your own risk and may fail to load or crash Stellarium. This setting does not resize PeakFinder textures.

ground_col

Color of ground. Defaults to Stellarium's default.

hor_col

Colour of a polygonal horizon line. Textured DEM and PeakFinder landscapes omit this line.

Details

A landscape lets the same terrain obstruction be used in a planetarium reconstruction. The export pairs the profile's azimuth and altitude samples in a polygonal horizon file and records the site, appearance and attribution in a Stellarium configuration. The export describes the horizon geometry; the altitude-uncertainty series remains in the R object.

DEM and SVG panoramas use a spherical landscape with the PNG rotated -90 degrees for Stellarium's east-origin mapping. A new PeakFinder import also records the original ZIP location. If native tiles are requested and that archive still matches its checksum and contains the supported calibrated eight-tile landscape, Stellarium uses those original textures and their angular settings instead. The export also includes the skyscapeR numerical profile and SVG-derived PNG. exportStellarium is an alias for exportHor.

The ZIP is saved as name-horizon.zip in the calling working directory. Choose a new archive name each time. Names cannot contain path separators or line breaks. Export requires a working system ZIP command.

Value

Invisibly, the absolute path of the created ZIP archive.

Validation

H07 checked that a partial photograph is rejected for both image and numerical landscape export. See the H07 check in the technical manual.

References

Stellarium User Guide, chapter on landscapes and texture sizes.

See Also

Examples

# Export a measured horizon from the example dataset.
## Not run: 
hor <- malta_horizons[[1]]
exportStellarium(hor, name = "Malta survey")
# For a DEM panorama, reduce the texture width on a memory-limited machine.
terrain <- createHor(dem = "terrain.tif", loc = c(51.19, -1.75))
exportStellarium(terrain, name = "Survey terrain", max.texture.width = 2048)

## End(Not run)
