Function index · parallax.corr() method

Estimate the parallax correction to declination

Description

Estimate how the observer's position on Earth shifts a solar or lunar target declination relative to its geocentric value.

Usage

parallax.corr(parallax, loc, altitude = 0)

Arguments

parallax

Average parallax to correct (e.g. 0.00224 for the Sun, or 0.952 for the Moon)

loc

This can be either the latitude of the location, or a skyscapeR.horizon object.

altitude

Altitude of the celestial object. Defaults to 0 degrees.

Details

The limiting-declination functions subtract this approximate correction from their geocentric target. The correction in degrees is the supplied parallax multiplied by the cosine of altitude and sine of latitude, with the angular arguments evaluated in degrees. The sign therefore reverses between hemispheres. This scalar approximation is distinct from computing an instantaneous topocentric ephemeris.

Ruggles gives an archaeological example of applying mean lunar parallax in a declination calculator.

Value

Numeric declination correction in degrees. The sign depends on latitude.

Validation

A05 compared the returned correction with the signed spherical approximation in both hemispheres. See the A05 check in the technical manual.

References

Ruggles, C. L. N. Basic declination calculator. https://web.cliveruggles.com/tools/declination-calculator.

See Also

Examples

# Parallax correction for the moon, as seen from latitude 50ºN and at 0º altitude
parallax.corr(0.952, 50, 0)
