Function index · eq() method

skyscapeR 2.0.9004

Estimate solar declination at an equinox

Description

Estimate the solar declination associated with the astronomical equinox, optionally applying a site-dependent parallax correction.

Usage

eq(loc = FALSE, parallax = 0.00224, altitude = 0, verbose = TRUE)

Arguments

loc

Latitude in degrees north or a skyscapeR.horizon object. Omit this argument or use FALSE for geocentric declination.

parallax

Mean horizontal parallax in degrees. The default is 0.00224 degrees for the Sun.

altitude

Altitude of the sun. Defaults to 0 degrees.

verbose

Logical to control output of warnings and messages. Defaults to TRUE. This affects messages only, not the calculated declination.

Details

The geometric reference at an equinox is the celestial equator, with geocentric declination zero. Supplying a location subtracts the package's approximate parallax correction for the latitude and specified altitude. The result is a declination target in degrees; no equinox date, event time or horizon crossing is calculated.

Value

Numeric declination in degrees. With loc = FALSE the result is geocentric. Supplying a location applies the parallax correction for the chosen altitude.

See Also

obliquity, jS, zenith, antizenith, spatial.equinox, parallax.corr, dS

Examples

# Equinoctial geocentric declination:
eq()

# The same geocentric result without a message:
eq(verbose=FALSE)

# Topocentric declination at latitude 50 degrees N:
eq(loc=50)
