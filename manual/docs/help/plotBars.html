Function index · plotBars() method

Plot orientation intervals in declination

Description

Compare central orientations and their angular uncertainties across observations, optionally against celestial target ranges.

Usage

plotBars(
  val,
  unc,
  names,
  unit = "Declination",
  obj,
  show.obj.label = TRUE,
  xrange,
  yrange,
  sort = FALSE,
  shade = TRUE,
  mark = TRUE,
  col = NULL,
  geometry = if (missing(shade)) "interval" else "bar",
  show.legend = TRUE,
  style = "publication-colour"
)

Arguments

val

Array of declination or azimuth values.

unc

Single value or array of measurement uncertainty

names

Array of names of measurements in val

unit

(Optional). Either 'Declination' or 'Azimuth'. Defaults to 'Declination'.

obj

A skyscapeR.object from skyObject, or a list of these objects. Each group retains its own epochs and styles for displaying the declination values of celestial objects.

show.obj.label

Logical. Label celestial overlays on the declination plot. Defaults to TRUE.

xrange

Array of limits for x-axis.

yrange

Array of limits for y-axis.

sort

Logical to control whether to sort the measurements by their declination value. Defaults to FALSE

shade

Logical to control whether to shade a polygon of measurements. Defaults to TRUE

mark

Logical to control whether to mark the declination value. Defaults to TRUE

col

Measurement colour. NULL uses the current style.

geometry

Use "interval" for sightline intervals with a centre point, or "bar" for filled or outlined rectangles. Explicitly supplying the older shade setting selects rectangles unless geometry is supplied.

show.legend

Display target annotations when show.obj.label is also TRUE.

style

Analytical display style, either "publication-colour" (default) or "publication-mono". Monochrome uses grayscale and preserves line styles.

Details

A row represents one measurement. Its horizontal bar spans the supplied value minus and plus its uncertainty, and an optional mark shows the centre. A scalar uncertainty is reused for all rows. Sorting rearranges measurements, labels and widths together. Celestial overlays use the declination axis. The widths reflect the supplied uncertainties and acquire a probability interpretation only from the measurement model.

For a two-year epoch range, celestial targets are displayed as bands covering their stored minimum and maximum declinations across the full plot height. Single-year targets are displayed as lines.

Value

Draws orientation measurements and their uncertainties on the active graphics device.

Coordinates and interpretation

unit labels the measurement axis; it does not transform azimuths into declinations. Celestial overlay values are declinations. Use them with declination measurements, or convert measurements first using the appropriate site and horizon. Bars show the supplied symmetric angular bounds, not fitted confidence intervals. Use az.pdf, coordtrans and spd when the full measurement distributions are needed.

Validation

W01 checked the endpoints and row labels of an azimuth interval spanning north. See the W01 check in the technical manual.

See Also

skyObject

Examples

# Plot some declination data:
decs <- c(10, 12, -5, 4)
plotBars(decs, unc=5)

# To visualize this data against the common solar and lunar targets:
tt <- skyObject(c('solar extremes','lunar extremes'), epoch=-2000, lty=c(2,3))
plotBars(decs, unc=5, obj=tt)
# Display a year-range target band:
targets <- skyObject('solar extremes', epoch=c("4001 BC", "2001 BC"), col='red')
plotBars(c(-24,-23,23,24), unc=0.5, obj=targets)
