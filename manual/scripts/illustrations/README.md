# Figure sources and reproduction

Run `Rscript scripts/illustrations/extract.R` with skyscapeR 2.0.9004 installed, then `python scripts/illustrations/draw.py` from the book root. The Python script uses NumPy, pandas, Pillow, SciPy and Matplotlib. The extracted class grid and saved Ġgantija fit tables are included for reproduction without R. Quarto uses the resulting images directly.

- **Milky Way.** The source is the archived celestial-coordinate diffuse-light image used by the tracing scripts (milkyway_2020_4k_print.jpg from Deep Star Maps 2020; archived PNG input). Credit: Ernie Wright, NASA/Goddard Scientific Visualization Studio; ESA/Gaia/DPAC. https://svs.gsfc.nasa.gov/4851/ . The Galactic reprojection follows the axes and rotation in the development archive. The outer boundary and class plot use the grid in the tested package. The two contrast reviews are the original centre and anticentre comparison images, preserved independently of this redraw.
- **Terrain and survey.** The worked synthetic two-ridge surface and instrument readings are described in horizons.qmd and field-reduction.qmd. The ray diagram samples the associated analytic surface at 2.5 m intervals and uses geometric angles. It is a schematic companion to the raster example.
- **Photographic horizons and declination.** The input mask, calibrated residuals, notch and summed density come from the examples already shipped with the manual (archives/conventions-field-panorama.zip and archives/doorway-and-ridge-examples.zip). The conditional-density panel uses the chapter's geometric equations with the same latitude, uncertainty and notch. The integrated curve is the recorded package output.
- **Stellar visibility.** The dawn track is deliberately synthetic. The chapter caption records its input functions. A model visibility interval is obtained by intersecting the four criteria at the same time.
- **Significance and H01.** The significance plot uses the empirical curve, bounds and returned cluster p-values from ggantija-random-500.rds. H01 uses the 334-bearing working sample in previous-edition/interim-results/bearing-residuals.csv inside the H01 reproducibility archive.
