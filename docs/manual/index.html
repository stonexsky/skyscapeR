skyscapeR technical manual

9 November 2026

About this edition

This is the technical manual for skyscapeR 2.0, with methods anchored to 2.0.9004 and versioned validation through 2.0.9011. The function catalogue and vignette guide were checked against 2.0.9012. It documents how the package calculates its results, which assumptions affect their interpretation and which comparisons have been made against independent observations. Each study names the build tested.

The measurement-model guide compares six ways to represent uncertainty and gives the assumptions behind each. In build 2.0.9012 the uniform opening convolved with Gaussian survey error defaults to a survey-error standard deviation of 0.5°.

For a first analysis, follow the worked vignette. The package README covers installation and migration to version 2.0.

Finding a method

Use the function index to find a help page or an implementation note by name. The methods guide groups the calculations by research question. The vignette guide connects each step in the worked analysis to its technical explanation.

Finding the evidence

A01, D01 and S03 report calendar, density and significance checks on build 2.0.9005 and the D01 and S03 corrections verified on 2.0.9006. S01 evaluates false positives and power for the uniform-orientation test in 2.0.9007. S02 covers specified models, H07 covers partial photographs, and W01 compares drawn coordinates with numerical results. A05, A08 and W02 cover solar limits, target selection and the field-to-sky replay. For astronomical positions and prehistoric lunar bearings, A02 compares skyscapeR with the parent JPL ephemerides and JPL Horizons. For terrain horizons, H01 measures field accuracy and H02 compares numerical skylines at matched viewpoints. For sky reconstruction, consult the Milky Way tracing and calibration and the sky-rendering studies. The heliacal-rising study evaluates event timing. The ephemeris chapter distinguishes upstream precision claims from independent tests of this package.
