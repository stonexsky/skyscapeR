Function index · plot.skyscapeR.spd() method

Plot a summed orientation density

Description

Visualise concentrations of orientation density across a group of structures.

Usage

## S3 method for class 'skyscapeR.spd'
plot(
  x,
  xrange,
  yrange,
  title = NULL,
  col = NULL,
  shading = TRUE,
  ...,
  obj = NULL,
  xlim,
  ylim,
  show.legend = TRUE,
  style = "publication-colour"
)

Arguments

x

A skyscapeR.spd object created with spd

xrange

Range of x-axis to plot.

yrange

Range of y-axis to plot.

title

Title to add to the plot.

col

Observed density colour. NULL uses the current style.

shading

Logical to control whether to color the entire distribution. Defaults to TRUE

...

Additional arguments to be passed to plot.

obj

A skyObject or list of target groups for a density or significance plot. Declination plots show single epochs as lines and epoch ranges as bands. Azimuth plots use each group's site latitude to mark rising and setting boundary bearings at a geometric level horizon.

xlim

Earlier name for xrange.

ylim

Earlier name for yrange.

show.legend

Show the observed-curve and celestial-target key when target overlays are supplied.

style

Analytical display style, either "publication-colour" (default) or "publication-mono". Monochrome uses grayscale and preserves line styles.

Details

A peak can arise where several uncertain sightlines coincide. The horizontal axis uses the summed curve's stored coordinate and the vertical axis its density. Optional shading fills the area beneath the curve; changing colours or axis limits does not renormalise it. Whether its integral is one depends on the normalisation used when creating the object. Assess departures from a specified null using a significance test.

Value

Draws the summed density against its angular coordinate on the active graphics device.

Validation

In W01 the drawn line matched the stored coordinates and heights of the summed density. See the W01 check in the technical manual.

See Also

spd, plot.skyscapeR.pdf

Examples

az <- az.pdf(az = c(85, 92), unc = 2, verbose = FALSE)
plot(spd(az))
