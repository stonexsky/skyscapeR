Function index · modelTest() method

Test orientations against a specified null model

Description

Use a Monte Carlo significance test to assess whether the measured orientations of a group of structures are compatible with a specified null model in azimuth or declination. The model can be shared across sites or specific to each site.

Usage

modelTest(
  pdf,
  model,
  unc = NULL,
  nsims = 1000,
  conf = 0.95,
  tails = 2,
  normalise = FALSE,
  .res = 0.01,
  ncores = NULL,
  verbose = TRUE
)

Arguments

pdf

Empirical skyscapeR.pdf from az.pdf, dec.pdf or coordtrans. Its coordinate selects the simulation path.

model

One shared data frame or an ordered list with one table per observation. The first column contains candidate coordinates in degrees and the second contains nonnegative discrete sampling weights, with at least one positive weight. On equally spaced grids, density heights can serve as weights.

unc

Optional replacement width in degrees of the tested coordinate. Use a standard deviation for normal, half the total span for triangular, or the family-specific half-width documented in az.pdf. Supply a scalar or one per observation. Omit to reuse stored measurement uncertainties or mean-shift transformed declination curves. See Details.

nsims

Number of simulations, at least two. Default is 1000.

conf

Confidence level as a fraction.

tails

1 for upper excesses, 2 for excesses and deficits.

normalise

Scale each summed density to unit area before comparison.

.res

Spacing of the empirical and simulated comparison grids in degrees. Default 0.01.

ncores

Worker count. By default use half the detected available logical cores, rounded down with a minimum of one. Set ncores=1 for serial execution. The simulation count and memory batch size can further limit workers. Verbose output reports the effective count.

verbose

Display simulation progress.

Details

A proposed topographical or astronomical explanation can predict some orientations more frequently than others. Testing that explanation requires simulating its predicted distribution at the sites under study.

Silva and Lomsdalen (2025) extended the random-orientation framework of Silva (2020) to test specific hypotheses about temple orientations in Malta, including topographical and astronomical explanations. Here the hypothesis specifies the relative probability of each candidate orientation. A small global p-value is evidence against that particular model.

The input PDF determines the coordinate of the test. Express the model coordinates and uncertainties in that same coordinate. Each simulation draws one centre per observation according to the weights in its model table. The function constructs an azimuth or declination density around each centre and sums these densities on the same comparison grid as the observed SPD. The observed measurement curves are used as supplied.

Measurement uncertainty. Direct measurement PDFs reuse the family selected in az.pdf or dec.pdf, including the observation's taper, survey error and triangular asymmetry. A direct triangular model is positioned by its mode. Overriding unc rescales its two sides in proportion; for the two softened uniform families the taper or survey-error SD stays fixed in degrees. For declinations from coordtrans, omit unc to use each observation's own density as a template. A model draw represents the expected mean declination for that observation. The function calculates the density-weighted mean of its piecewise-linear curve and adds (draw minus mean) to every declination. For example, a curve with mean -17.6 degrees shifts by -4.4 degrees for a draw of -22 degrees. The shift preserves the curve's width, asymmetry and peaks before interpolation onto the comparison grid. It requires only the stored declination curve and assumes its shape applies at the modelled mean. A positive-weight candidate that would shift density beyond -90 or +90 degrees raises an error. An explicit unc selects a normal density around each simulated centre for transformed input. With normalise=TRUE, each final SPD has unit area.

Reading the result. The global p-value compares the departure of the entire observed curve with departures under the specified model. Local results use the largest qualifying cluster per simulation to adjust for searching the grid. Boundaries describe where departures were observed. The envelope is pointwise. Both tests use inclusive Monte Carlo ranks, with minimum p-value 1/(nsims + 1). See randomTest for the shared scoring rules, width threshold, treatment of ties and zero variance, and assumptions behind the adjustment. When a model was fitted to the same observations, its fitting procedure must be accounted for separately.

Running simulations. With a fixed seed, sampling in the calling session gives the same result for different worker counts. For grids larger than 16 MiB, allow about eight bytes of temporary disk space per simulation per grid point. Temporary files are removed on return or error.

Value

A skyscapeR.sigTest list with settings and global/local results in metadata, empirical density and null envelope in data.

Validation

In S03, independent scoring reproduced the azimuth and declination ranks on their respective grids. Build 2.0.9006 counts north once and reports one interval for a qualifying excess across north. Refit earlier azimuth tests to obtain the revised probabilities. See S03 validation in the technical manual.

In S02, identical candidate bearings produced identical directly constructed observed and simulated densities on build 2.0.9008. Global rejection at the 5 percent level ranged from 4.35 to 5.50 percent under the six matched null designs. See the S02 check in the technical manual.

Model weights and interpretation

Weights are discrete sampling probabilities up to proportionality. If a continuous model is evaluated on an uneven coordinate grid, density heights alone do not represent probability mass; construct weights that account for the bin widths before calling the function. Put site-specific model tables in the same order as the observed measurements.

A large p-value does not prove the proposed explanation or measure its probability. The test asks whether the specified model is incompatible with the observed departure statistic. Alternative models can remain compatible. The simulations do not automatically represent dependence between sites, selection after viewing the data, or uncertainty in fitted model parameters. See randomTest for study-design and Monte Carlo limitations.

Examples

d <- dec.pdf(dec = c(-18, 12), unc = c(0.8, 1.4))
m <- list(data.frame(x = -20:-16, w = 1), data.frame(x = 10:14, w = 1))
set.seed(42)
fit <- modelTest(d, m, nsims = 10, .res = 0.5,
                 verbose = FALSE)
print(fit)
## Not run: 
set.seed(42)
fit <- modelTest(d, m, nsims = 5000, ncores = 2)
# For transformed observations, model coordinates specify mean declinations.
Az <- az.pdf(az = c(87, 110), unc = 2)
hor <- createHor(az = c(0, 360), alt = c(0, 0), alt.unc = 0.1, loc = c(35, -8))
Dec <- coordtrans(Az, hor)
fit <- modelTest(Dec, data.frame(x = c(-22, 18), w = c(1, 1)))
