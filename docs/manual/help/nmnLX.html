Function index · nmnLX() method

skyscapeR 2.0.9004

Estimate northern minor lunar standstill declination

Description

Estimate the northern declination limit of a minor lunar standstill for comparison with a proposed alignment.

Usage

nmnLX(
  year = skyscapeR.env$cur.year,
  loc = FALSE,
  parallax = 0.952,
  altitude = 0,
  verbose = TRUE
)

Arguments

year

Astronomical year. The default is the current year in the package settings. Historical labels such as "3700 BC" are accepted by astroYear.

loc

Latitude in degrees north or a skyscapeR.horizon object. Omit this argument or use FALSE for geocentric declination.

parallax

Mean horizontal parallax in degrees. The default is 0.952 degrees for the Moon.

altitude

Altitude of the Moon. Defaults to 0 degrees.

verbose

Logical to control output of warnings and messages. Defaults to TRUE.

Details

A minor standstill defines a limiting lunar declination at the epoch of interest. The model uses the obliquity minus a fixed 5.145 + 0.145 degrees, then applies the positive sign for the northern limit. With a location it subtracts the parallax correction for latitude and altitude. The default lunar parallax is 0.952 degrees. This approximation defines a target limit; it does not search a time series for an actual lunar event.

Sprajc (2016) describes the limits set by obliquity and the mean lunar inclination. This package also includes the fixed 0.145-degree term above.

Value

Numeric declination in degrees. With loc = FALSE the result is geocentric. Supplying a location applies the parallax correction for the chosen altitude.

References

Šprajc, I. (2016). Lunar alignments in Mesoamerican architecture. Anthropological Notebooks 22(3), 61-85.

See Also

smnLX, nMjLX, sMjLX, parallax.corr

Examples

# Northern minor Lunar Extreme geocentric declination for year 2501 BC:
nmnLX(-2500)

# Topocentric declination for same year and latitude of 50 degrees N:
nmnLX(-2500, loc=50)
